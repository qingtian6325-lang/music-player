⚙️ 播放器设置

🌐 音乐 API 音源服务选择 (支持智能多源瀑布降级)

默认以 GDStudio 专属独立 API 节点为主源（第二优先级为官方 Web 节点），支持智能多源瀑布容灾（逐级流转至 Meting / Qijieya / Injahow 等），您也可以在此自由指定优先音源或自建节点。

🎧 默认音频音质偏好 (Quality Preference)

默认以最高母带无损规格优先解析（支持 FLAC 24bit/192kHz 等顶级音质），若歌曲无对应高规格则自动平滑降档。

🛡️ Cloudflare Worker 中转代理（办公室内网穿透）

本站默认使用高速中转（disablecdnblock.qingtian6325.workers.dev），点开即听，公司局域网也能顺畅使用。你也可以填自己的 Worker 地址覆盖它；清空则恢复默认中转。

🎵 歌词延迟补偿

换歌时有微小音频缓冲，让歌词提前或延后跟声音完美对齐（默认 520ms）。
