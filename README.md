# 音乐播放器

现代化网页版音乐播放器：首页九大榜单、多音源搜索、同步歌词、自建歌单、播放队列、专业均衡器、画中画桌面悬浮歌词与睡眠定时，纯静态开箱即用。

## 核心特性

- 🏠 **精选热门榜单**：首页预置 9 大精选榜单（飙升 / 新歌 / 热歌 / 古典 / 电音 / ACG / 欧美 / 日语 / 韩语）
- 🔍 **全网搜索与增强体验**：
  - 支持网易云 / JOOX / B站 三大多源搜索
  - 搜索历史记录（支持单项删除与一键清空）
  - 热门推荐标签（周杰伦、陈奕迅、林俊杰、Taylor Swift 等一键直达）
  - 搜索结果分页支持（底部「加载更多歌曲」浏览海量结果）
- 📑 **实时播放队列管理**：
  - 侧边独立抽屉式播放队列，实时展示待播曲目与时长
  - 支持单曲立即播放、移出队列、一键清空队列
  - 歌曲菜单支持「下一首播放」、「加入待播队列」
- 🎚️ **Web Audio 专业均衡器与音效**：
  - 5 段精准微调（60Hz、250Hz、1kHz、4kHz、12kHz）
  - 8 大精调音效预设：平衡、低音震撼、纯净人声、流行金曲、摇滚力量、电音派对、优雅古典、3D 沉浸环绕
  - 0.75x ~ 2.0x 随心倍速播放调节
  - 实时动态频谱波形动效（全屏与歌词面板舞动柱状图）
- 🪟 **桌面画中画悬浮歌词 (Picture-in-Picture)**：
  - 采用标准 Canvas + PiP 实时渲染双语滚动歌词
  - 即使切换到其他软件、敲代码或玩游戏，歌词也可悬浮在桌面最顶层
- ⏱️ **睡眠定时关闭**：
  - 15 / 30 / 45 / 60 / 90 分钟或自定义时长倒计时
  - 支持「当前歌曲播完后自动停止」
  - 结束前 12 秒音频柔和淡出，呵护入眠
- 📂 **自建歌单与导入**：
  - 支持在本地浏览器自由创建个人歌单，支持重命名与管理
  - 任意歌曲通过「…」菜单一键加入自建歌单
  - 支持网易云 / Spotify / Apple Music / YouTube 歌单链接解析导入
- 🎤 **双语同步滚动歌词**：
  - 翻译歌词对照、点击任意歌词行快速跳转音频定位
  - 支持全屏沉浸歌词模式、环境光色彩联动
  - 歌词字号缩放（A- / A+）与一键复制完整歌词
- 🔊 **高保真音质自动降级**：
  - 音质默认请求最高可用档位（999 无损 24bit → 740 无损 16bit → 320K → 128K 自动切换）
  - 播放条实时展示当前歌曲生效音质徽章
- 💾 **数据备份与恢复**：
  - 一键导出所有收藏、自建歌单与设置至 JSON 备份文件
  - 支持一键导入还原，跨设备、清理缓存无忧
- ⌨️ **便捷快捷键**：
  - `Space`：播放 / 暂停
  - `←` / `→`：上一首 / 下一首
  - `↑` / `↓`：音量调节 (+/- 5%)
  - `M`：静音切换
  - `L`：打开 / 关闭歌词面板
  - `Q`：打开 / 关闭播放队列
  - `Esc`：关闭正在播放全屏与各类浮层弹窗
- 📱 **移动端与全设备适配**：
  - 底部便携导航条（首页、搜索、收藏、队列、设置）
  - 横屏与车机大屏触控优化

## 本地运行

```bash
cd music-player
python3 -m http.server 8080
# 浏览器打开 http://localhost:8080
```

## 部署

纯静态项目，提交到 GitHub 后通过 GitHub Pages 自动部署上线；亦可直接拖拽部署到 Netlify、Cloudflare Pages 或 Vercel。
