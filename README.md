# 音乐播放器

网页版音乐播放器：首页九大榜单、搜索、同步歌词、收藏，打开即用。

## 功能

- 🏠 首页九大榜单（飙升 / 新歌 / 热歌 / 古典 / 电音 / ACG / 欧美 / 日语 / 韩语）
- 🔍 搜索歌曲 / 歌手 / 专辑（网易云 / JOOX / B站 三个音乐源）
- 🎵 播放 / 暂停 / 上一首 / 下一首 / 进度拖动 / 音量
- 🔁 顺序 / 随机 / 单曲循环
- 🎤 同步滚动歌词（点击歌词可跳转），含翻译
- 🔊 音质默认取最高可用（999 → 740 → 320 → 128 自动降级），播放条显示实际音质
- ❤️ 收藏歌曲（保存在浏览器本地）
- ⌨️ 快捷键：空格播放/暂停，←/→ 切歌

## 数据接口

音乐数据来自 [GD音乐台](https://music.gdstudio.xyz)（`music-api.gdstudio.xyz`），License：CC BY-NC 4.0。
本站仅供学习交流，请勿商用。如有侵权请联系删除。

## 本地运行

```bash
cd music-player-public
python3 -m http.server 8080
# 浏览器打开 http://localhost:8080
```

## 部署

纯静态网站，直接部署到 GitHub Pages / Netlify / Vercel 即可。
